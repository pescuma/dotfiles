# Dotfiles

Personal configuration files managed with [chezmoi](https://www.chezmoi.io/).

This repository is intended for personal use. Do not modify, delete, or apply configurations unless you know what you're doing.

## Setup

```sh
chezmoi init --apply <username>
```

## Commands

```sh
chezmoi update      # Pull and apply changes
chezmoi diff        # Preview changes
chezmoi apply       # Apply configurations
chezmoi add <file>  # Track a file
chezmoi edit <file> # Edit a managed file
chezmoi cd          # Open source directory
```
